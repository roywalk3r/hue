Nuxt Frontend — Architecture Options

3 ways to connect the Nuxt frontend to the Hue API backend

Option A

SPA with Direct API Calls

Nuxt in SPA mode. Client makes direct fetch() calls to backend at localhost:24608. Backend CORS handles origin validation.

Pros

  • Simplest architecture
  • Fast dev iteration
  • No server overhead in Nuxt

Cons

  • No SSR, no SEO for content pages
  • CORS configuration needed per env
  • Slow initial JS bundle load
Option B (Recommended)

SSR with Server API Proxy

Nuxt server routes proxy all API requests to the backend. Content pages are SSR'd for instant load + SEO. Playback stays client-side.

Pros

  • Content pages SSR — fast FCP + SEO
  • Unified origin — no CORS issues
  • Backend URL is server-side secret
  • Can add caching layer in Nuxt server

Cons

  • Nuxt server adds a hop
  • More complex deployment
  • SSE streaming passthrough needed
