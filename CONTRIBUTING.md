# Contributing to Hue

## Getting started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/your-username/hue`
3. Install dependencies: `npm install`
4. Copy the env file: `cp .env.example .env` and add your TMDB API key
5. Start the dev server: `npm run dev`

## Making changes

- Create a feature branch: `git checkout -b feature/my-change`
- Make your changes and commit with a clear message
- Run `npm run lint` before committing
- Push and open a pull request

## Reporting issues

Please search existing issues before opening a new one. Include steps to reproduce and your environment details.
