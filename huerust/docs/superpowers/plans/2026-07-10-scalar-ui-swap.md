# Scalar UI swap for huerust `/api/docs` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the `utoipa-swagger-ui` mount at `huerust::/api/docs` with `utoipa-scalar = "0.3"`, reusing the existing `ApiDoc::openapi()` spec verbatim.

**Architecture:** Two-file dependency-and-mount swap. The `Scalar` crate accepts the same `utoipa::OpenApi` output the existing `ApiDoc` struct emits, so no spec-regeneration, route-annotation, or schema work is required. The mount stays at `/api/docs` so bookmarks and upstream caller links continue to work. The 12 hand-written Markdown files and the pre-existing 403 on `/api/docs/openapi.json` are explicitly out of scope.

**Tech Stack:** Rust 2021, axum 0.7, `utoipa = "4"` (unchanged), `utoipa-scalar = "0.3"` (new), `utoipa-swagger-ui` (removed).

## Global Constraints

- Crate version pin: `utoipa-scalar = "0.3"` — no features needed; the axum mount is in the crate's core API.
- Mount path is exactly `/api/docs` (verbatim — preserves existing bookmarks and the dev-server URL).
- Spec argument is `crate::openapi::ApiDoc::openapi()` — do not re-export, re-wrap, or rebuild the spec; the `Scalar::with_url` call must receive this exact value.
- `Cargo.lock` will be regenerated by `cargo build`; the implementer must commit the updated lockfile alongside `Cargo.toml`.
- `cargo test` baseline is 117 passing tests as of the commit before this change. No test count regression is acceptable.
- Out of scope: `#[utoipa::path]` annotations on unannotated routes, the 403 on `/api/docs/openapi.json` (pre-existing auth-middleware bug), and the 12 hand-written Markdown files.
- Working branch: `feat/kisskh-catalog`. Do not commit to `main`.
- Conventional commit subject: `feat(docs): swap Swagger UI for Scalar at /api/docs`.
