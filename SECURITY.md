# Security Policy

## Supported Versions

Only the latest version of Hue Stream API is supported. If you are using an older version, please upgrade to the latest release on the [main branch](https://github.com/roywalk3r/hue).

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| < 1.1.0 | :x:                |

## Reporting a Vulnerability

I take security seriously. If you discover a security vulnerability within Hue Stream API, please send an e-mail to `roywalker440@gmail.com`.

Please include:
*   A description of the vulnerability.
*   Steps to reproduce the issue.
*   The potential impact of the vulnerability.

I will acknowledge your report and work to address the issue as quickly as possible. Please do not open public issues for security vulnerabilities.
