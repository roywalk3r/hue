Hue Stream Diagnostic Player

Fetches /api/streams, kkey-decrypts every stream, and plays each one in isolation so you can see which sources are playable and how fast they start — independent of the Nuxt frontend.

Enter KKEY + API key (saved locally), then Fetch.

Open via file:// or python3 -m http.server in public/. The backend allows cross-origin (permissive CORS), so either works.
