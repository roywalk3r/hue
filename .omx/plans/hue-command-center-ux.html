Turn Hue into a media control room.

The backend already aggregates streams, live sports, discovery, proxying, and provider health. The new product should make that power visible: dense discovery, resilient playback, live diagnostics, and protected operator controls in one cinematic interface.

Phase zero is non-negotiable.

  • Fix `/api/streams` cache-miss crash before the frontend leans on provider aggregation.
  • Protect config, cache, debug, and password routes with authenticated sessions.
  • Block private-network targets in `/api/proxy` so the UI cannot expose an SSRF path.
  • Rotate tracked secrets and stop rendering sensitive config in public surfaces.

Design language

Graphite base, real media imagery, sharp panels, status colors, compact controls, visible provider confidence, and motion only for real state changes.

Acceptance

Verification path

The UI is only awesome if it survives real backend conditions: slow providers, no streams, bad proxy targets, and protected admin routes.

  • `/api/streams/movie/:id` returns JSON on cache miss instead of throwing.
  • Config, debug, cache, and password endpoints reject unauthenticated requests.
  • `/api/proxy?url=` blocks localhost and private network targets.
  • First viewport shows hero, rails, live/system state, and search on mobile and desktop.
  • Watch page shows loading, playable, and provider/proxy failure states.
  • Status page exposes provider health without leaking secrets.
